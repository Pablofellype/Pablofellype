## 🚀 Projetos em Destaque

### 📋 Sistema de Auditoria e Controle
*Substituição completa de mais de 12 planilhas corporativas e controles manuais em papel.*
* **Impacto:** Obteve **100% de aprovação** consecutiva em duas auditorias governamentais rígidas.
* **Recursos:** Cálculo automatizado de compliance trimestral, disparo automático de alertas e geração robusta de relatórios PDF.
* **Stack:** `Node.js` · `Express` · `MySQL` · `Docker`

### 📱 Plataforma PWA de Inspeção e Acompanhamento
*Ferramenta móvel instalável focada em auditoria de pátio fabril e galpões logísticos.*
* **Recursos:** Funciona Offline (PWA), controle com 3 níveis de permissão (Admin, Colaborador e Visitante), checklists operacionais dinâmicos com anexo de imagens e relatórios automáticos.
* **Stack:** `Node.js` · `JavaScript` · `Tailwind CSS` · `MySQL`

### 📊 Plataforma de Avaliação por QR Code
*Totens de feedback e pesquisas rápidas de satisfação integrando diversos setores.*
* **Recursos:** Validação e autenticação de matrículas de colaboradores em tempo real, painel administrativo dinâmico e cobertura em 11 setores.
* **Stack:** `HTML` · `CSS` · `JavaScript` · `Node.js` · `Vite`

### 📦 Portal de Solicitação de Materiais
*Logística integrada para distribuição de fardamentos, EPIs e materiais de consumo.*
* **Recursos:** Catálogo digital completo com fotos, inteligência para detecção de solicitações duplicadas e rastreamento de status por protocolo.
* **Stack:** `HTML` · `CSS` · `JavaScript` · `Node.js`

### 🌐 Landing Page para Tráfego Pago
*Página de destino institucional otimizada para captação ágil de novos clientes.*
* **Recursos:** Foco em velocidade de carregamento (Performance >95 PageSpeed), SEO On-page e design responsivo fluido.
* **Stack:** `HTML` · `CSS` · `JavaScript` · `SEO`

## 💻 Como Visualizar este Portfólio Localmente

Este repositório também serve como o código do meu **Portfólio Web Interativo** (com terminal integrado, efeitos sonoros sintetizados e partículas). 

Para rodá-lo na sua máquina:

1. Clone o repositório:
   ```bash
   git clone https://github.com/Pablofellype/Pablofellype.git
   ```
2. Abra a pasta do projeto:
   ```bash
   cd Pablofellype
   ```
3. Execute o arquivo `index.html` em seu navegador ou utilize a extensão **Live Server** do VS Code para uma melhor experiência.
